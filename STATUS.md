## Ограничения и непроверенное

- Сервер загрузки Qt из исходной облачной среды возвращает `403 Forbidden` на CONNECT. Готовая открытая Qt 6.12.0 успешно установлена в Linux GitHub Actions; это другой сетевой контекст. Версия Qt не изменена.
- Windows в запуске 40875460579 остановился на установке Qt: `Failed to locate XML data for Qt version '6.12.0'`. Компиляция Windows и архив пока НЕ ПРОВЕРЕНЫ. Установщик изменён для прямого обращения к основному серверу Qt; итог повторного запуска будет записан отдельно.
- Первый запуск CI не смог получить первоначально выбранный SHA установщика. Исправлено закреплением доступной v4.5.0; это не изменение версии Qt.
- Windows 10, Windows 11, ALT Regular, CachyOS и Huawei — НЕ ПРОВЕРЕНО на реальных устройствах. Версии ОС/API/ABI ещё не сняты.
- Wayland/X11 на пользовательском Linux, Android APK, GMS-независимость, фон EMUI, кодеки, seek/gapless, WebDAV и кэши — НЕ ПРОВЕРЕНО; функции не реализованы.
- Архив CI не подписан. Перед публичным распространением нужны проверка полного состава лицензий/соответствующих исходников и выбор лицензии приложения. Личная проверка владельцем не объявляется публичным релизом.
- SDK Windows/Android в исходном Linux-окружении отсутствуют; Windows проверяется отдельным runner.
