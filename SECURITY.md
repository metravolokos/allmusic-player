# Security Policy

## Project status

AllMusic Player is an experimental, personal-use project. It is **not production-ready**, and no supported release or security response schedule is offered. A real WebDAV cloud connection and Android audio playback have not yet been accepted as operational features.

## Reporting security concerns

- **Do not post credentials, access tokens, private audio files, or exploit details in public issues, pull requests, or build logs.**
- If GitHub's **Private vulnerability reporting** is enabled for this repository, use the repository's **Security → Report a vulnerability** flow.
- If that feature is not available, the project does **not currently advertise a confidential vulnerability submission channel**. Do not assume public issues are private.
- For non-sensitive observations, follow [CONTRIBUTING.md](CONTRIBUTING.md).

The owner may review security feedback when possible, but no response time, remediation time, or third-party security support is promised.
