# Contributing to AllMusic Player

**This repository represents a personal, highly specialized software project, not an open-ended community product.**

The owner sets priorities according to individual requirements. External issue reports, suggestions, discussions, and pull requests are welcome only at the owner's discretion; there is **no commitment to review, accept, implement, maintain, or support them**.

If you propose a change:

1. Read the project purpose and limitations in [README.md](README.md) and [STATUS.md](STATUS.md).
2. Keep the proposal small and focused. Do not interpret the public roadmap as a promise to third parties.
3. Use a pull request; changes to protected `main` require the owner's decision and successful checks.
4. State the expected behavior, how you tested it, and the limitations. Do not claim real cloud or Android audio was tested unless evidence exists.
5. Never include personal music, cloud credentials, keys, tokens, or private user data in commits, issues, logs, or CI artifacts.
6. Follow [CODE_OF_CONDUCT.md](CODE_OF_CONDUCT.md). Report sensitive security problems as described in [SECURITY.md](SECURITY.md).

The owner may close unsolicited requests or pull requests without adopting them. Please do not contact the owner outside the repository to demand support or features.

For Russian-language context, see [README.ru.md](README.ru.md).
