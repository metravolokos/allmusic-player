# Code of Conduct

AllMusic Player is a personal, highly specialized project maintained at the owner's discretion. Public visibility does not make it a community service or create an obligation to provide support.

## Respectful participation

Technical disagreement, critical code review, and questions about AI-assisted development are permitted. Address the **work and evidence**, not the person's intelligence, background, identity, or perceived technical skill.

Personal insults, harassment, threats, discriminatory abuse, targeted ridicule, persistent unwanted contact, deliberate disruption, and spam are not acceptable.

## Scope and moderation

These rules apply to issues, pull requests, comments, and other project discussions. The repository owner may hide or remove inappropriate comments, close or lock conversations, restrict interactions, or block participants using GitHub's moderation tools. Not every technical disagreement warrants moderation.

For abuse, use GitHub's reporting tools where appropriate. Please do not post personal information, credentials, or sensitive security findings publicly; see [SECURITY.md](SECURITY.md).

The owner is not obligated to engage with every comment, provide support, or accept feature requests.
