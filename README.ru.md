# AllMusic Player

**[English version](README.md)**

**Персональный музыкальный плеер для Windows, Linux и Android, разрабатываемый для узкоспециализированных личных задач.**

AllMusic Player создаётся для конкретной медиатеки и индивидуальных сценариев использования владельца. Репозиторий открыт для просмотра и удобства разработки, **но это не коммерческий продукт и не универсальный плеер для широкой аудитории**.

> **Статус: ранняя разработка и технические прототипы.** Готового приложения для массового использования и публичной поддержки пока нет.

## Назначение проекта

Требования, архитектурные приоритеты и критерии приёмки определяются владельцем исходя из личных потребностей. Разработка функций для сторонних пользователей, поддержка произвольных конфигураций и универсальность не являются основными целями. Обязательств по технической поддержке, совместимости и срокам выпуска нет.

## Технологии и цели

- **Стек:** Qt 6, C++17, QML, CMake; общий программный фундамент и отдельные интерфейсы Desktop/Android.
- **Платформы:** Windows, Linux и Android.
- **Планируемый источник музыки:** личная облачная папка с доступом WebDAV только для чтения.
- **Исследованные аудиоформаты:** MP3, FLAC, AAC-LC (ADTS/M4A), ALAC (M4A).
- **Будущие возможности:** локальная медиатека, избранное, плейлисты, офлайн-кэш и устойчивое потоковое воспроизведение.

Это **цели разработки, а не перечень готовых к эксплуатации возможностей**.

## Что фактически проверено?

По состоянию на **30 октября 2026 года**:

- На физическом компьютере с Windows 11 владелец прослушал **5 из 5 тестовых потоковых форматов** через **локальный mock WebDAV**, включая Stop/restart и отказ сервера без поддержки HTTP Range.
- Автоматические тесты и прототипы успешно собирались на Linux и Windows; сборка и проверка Android APK также проходили. Начальный экран Android запускался на устройстве Huawei владельца.
- **Ещё не проверены:** подключение реального облачного WebDAV, потоковое воспроизведение через интернет с личным аккаунтом, звук на Android, полноценный офлайн-кэш и совместимость с произвольными компьютерами.

Подробности и доказательства: [STATUS.md](STATUS.md), [отчёт 001-E](docs/001-E-REPORT.md), [ROADMAP.md](ROADMAP.md).

## Организация разработки

Проект развивается **с применением ИИ**. Владелец определяет задачи и принимает результаты; ChatGPT помогает с требованиями, планированием и ревизией; Codex выполняет конкретные задачи через Pull Requests. Изменения проверяются автоматическими тестами и, где это требуется, ручной приёмкой. Применение ИИ не заменяет тестирование.
