# 001-A — безопасный исследовательский WebDAV

Статус: реализация разрешена владельцем 29.10.2026; подготовлена и автоматически проверена, ожидает приёмки. Результаты — [отчёт](../docs/001-A-REPORT.md).

## Цель для владельца

Выяснить, умеем ли мы безопасно читать список файлов и точные диапазоны байтов,
замечать смену версии файла и понятно завершать неудачные запросы.
Это проверка клиента на имитации, не доказательство возможностей Облака Mail.

## Область и ограничения

- Qt 6.12.0 / C++17 / Qt Network; существующая версия Qt не меняется.
- Асинхронный исследовательский клиент и локальный сервер без файлового хранилища.
- Клиент принимает только номер порта 127.0.0.1; адрес облака, пароль и логин не принимаются.
- Только PROPFIND и GET; никакого публичного метода отправки произвольного HTTP.
- Все пути ограничены /AllMusic с учётом кодирования, границ сегментов и origin.
- Редиректы отклоняются, включая редиректы внутри разрешённого корня.
- Никаких личных музыкальных файлов, реквизитов, реального WebDAV и GMS.
- Нет аудио, Android, SQLite или полноценного кэша; QMediaPlayer не выбран.

## Критерии приёмки

| ID | Проверка | Ожидаемый результат |
|---|---|---|
| A-01 | PROPFIND Depth:1, 207, DAV namespace и разные XML-префиксы | Список непосредственных детей; папки, размер, ETag, дата |
| A-02 | Отсутствующие/некорректные свойства, отдельный propstat 404 | Не выдумывать размер или ETag; остальные свойства сохранены |
| A-03 | Кириллица, пробелы, кодированные # и % | Корректный путь и фактический HTTP request-target |
| A-04 | .., encoded slash/backslash, double encoding, чужой origin, соседний префикс | Отклонение до HTTP; сервер не получает ни одного опасного запроса |
| A-05 | Враждебные href и редиректы 301/302/303/307/308 | href отфильтрованы; никакого перехода на второй сервер или за корень |
| A-06 | 206 и точный Content-Range, последний короткий диапазон | Точные байты и полный размер; заголовок Accept-Ranges не требуется |
| A-07 | 200 вместо 206, 416, неверный диапазон, короткое/лишнее тело | Никакой выдачи неправильного фрагмента за успешный |
| A-08 | Сильный/слабый/отсутствующий ETag, If-Range и смена версии | Возобновление только с сильным валидатором; другая/неподтверждённая версия не склеивается |
| A-09 | 401/403/404/408/429/5xx, обрыв, тайм-аут | Различимые ошибки, максимум 3 попытки, общий дедлайн |
| A-10 | Retry-After, отмена в запросе и при ожидании повтора | Ограниченное ожидание; после отмены запросы не возобновляются |
| A-11 | Медленный ответ | Event loop продолжает работать; параллельная операция отвергается |
| A-12 | Недоверенный TLS-сертификат | Клиент отклоняет соединение, HTTP до сервера не доходит |
| A-13 | Аудит HTTP каждого сценария | Клиент отправляет только GET/PROPFIND внутри /AllMusic; нет Authorization/Cookie |
| A-14 | Негативные запросы записи к отдельной имитации | Сервер отвечает 405; отсутствует файловое хранилище, которое можно изменить |
| A-15 | Сборка и автоматические тесты Windows/Linux | Реальные результаты и команды зафиксированы, непройденное обозначено |
| A-16 | Документация и PR | Понятные выводы для владельца, инструкция повторения, ограничения, STATUS актуален |

## Проверки и области изменений

`src/cloud/` — исследовательский клиент и консольная диагностика.
`tests/webdav/` — сервер, автоматические сценарии, публичный тестовый сертификат/ключ.
`CMakeLists.txt`, `.github/workflows/desktop.yml`, `scripts/package-webdav.ps1` — сборка,
проверки, готовый автономный Windows-архив стенда.
`docs/001-A-REPORT.md`, STATUS, ROADMAP, DECISIONS и README — результаты и ограничения.

В CI: существующие configure/build/ctest пресеты, webdav-safety и прежний window-smoke.
Ручная Windows 10 — первая пользовательская проверка готового архива. CI Windows
Server не считать результатом Windows 10. Архив не обращается к облаку.

001-A → 001-C → 001-B → 001-D; каждая задача требует отдельного разрешения.
