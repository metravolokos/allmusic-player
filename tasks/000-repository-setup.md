# Задача 000 — Основание проекта и подготовка репозитория

## Цель

Подготовить GitHub-репозиторий к безопасной поэтапной разработке Qt 6/C++/QML музыкального плеера. **Сначала инфраструктура и документы, не реализовывать функции приложения.**

## Что сделать

1. Изучить `SPEC.md`, `ARCHITECTURE.md`, `ROADMAP.md`, `DECISIONS.md`, `AGENTS.md`, `STATUS.md`.
2. Найти явные противоречия и спорные формулировки. Предложить изменения **сначала в виде плана** и дождаться подтверждения, если они меняют функциональные границы или архитектурные принципы.
3. Предложить конкретную фиксированную версию Qt 6, компилятора, CMake, JDK/NDK для Android с обоснованием совместимости и лицензий, без выдуманной «доказанной» работоспособности.
4. Создать минимальную структуру CMake-проекта, который открывает простой экран «AllMusic Player — проект запущен» на поддерживаемой CI-платформе. Не писать WebDAV/плеер/ИИ.
5. Добавить `.gitignore` для секретов, локальных настроек, сборок, кэша, SDK и IDE.
6. Настроить минимальные автоматические проверки документации/сборки там, где инструменты реально доступны. Если Android toolchain нет, **не** объявлять Android-сборку успешной.
7. Обновить `STATUS.md` и, при появлении утверждённых решений, `DECISIONS.md`.
8. Создать PR с понятным отчётом на русском языке.

## Границы

- Нельзя подключаться к реальному облаку и просить логин/пароль.
- Нельзя добавлять операции записи/удаления и реальные музыкальные данные.
- Нельзя декларировать поддержку кодеков и аудио без тестов.
- Не начинать задачу 001 самостоятельно.

## Критерии приёмки

- Минимальный проект собирается на реально проверенной платформе (указать команду и версию инструментов), либо зафиксирована воспроизводимая причина невозможности.
- Список зависимостей и их лицензий/ссылок указан в отчёте.
- Тестовый экран запускается там, где была доступна среда GUI; если headless CI, отмечено, что запуск не проверен.
- Нет секретов и аудиофайлов в репозитории/изменениях.
- В `STATUS.md` честно указано, что сделано и что не проверено.
- PR ограничен рамками задачи 000.

## Формат ответа

План → после утверждения реализация → тесты (команды/вывод) → ограничения → инструкция для пользователя без знаний C++ → ссылка на PR → предложение следующей задачи (не начинать).
