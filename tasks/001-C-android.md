# 001-C — минимальный Android APK

Источник: [Issue #5](https://github.com/metravolokos/allmusic-player/issues/5).
План и реализация разрешены владельцем 29.10.2026 с уточнениями в чате.

- Отдельная ветка от актуального main; PR без самостоятельного объединения.
- Qt 6.12.0 / C++17 / QML / CMake; общий запуск, отдельный мобильный экран.
- Первоначальный arm64-v8a APK разрешён даже без установленного ABI Huawei.
  Совместимость устройства НЕ ПРОВЕРЕНА до фактической установки и запуска.
- Android CI по pull_request с фильтром путей + workflow_dispatch; без push.
- Сохранить существующие Windows/Linux сборки, WebDAV и оконные тесты.
- Только экран, без звука, облака, файлов, БД, кэша, служб и GMS.
- Bundled runtime, временная debug-подпись без сохранения ключей, аудит APK,
  скачиваемый артефакт с маркировкой, суммами, лицензиями и инструкцией.
- Обновить статус принятой 001-A и ручного Windows 10 теста: 86 passed, 0 failed.
- Реальные результаты CI отделить от проверки Huawei. Не начинать 001-B/001-D.

Приёмка: успешный CI (Android APK + Desktop регрессия), аудит manifest/подписи/
ABI/зависимостей, понятная инструкция; затем ручная установка, отрисовка,
повороты, жизненный цикл, повторный запуск без сети и явное решение владельца.
Ссылки и ограничения — [отчёт](../docs/001-C-REPORT.md).
