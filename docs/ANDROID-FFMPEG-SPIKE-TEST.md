# Android Qt FFmpeg spike — проверка на Huawei

Это локальная проверка Android backend для Issue #24. APK содержит только
синтетические WAV/MP3/FLAC образцы. В нём нет подключения к Cloud Mail,
пользовательским файлам и сетевым разрешениям. Пакет имеет отдельный ID
`org.metravolokos.allmusicplayer.spike002d`, поэтому его можно установить рядом
с прежним тестом 002-A.

## Проверка

1. Скачайте Android artifact `AllMusicPlayer-002D-QtFFmpeg-Android-arm64-v8a-debug`
   из CI и установите APK обычным способом. Подпись временная debug.
2. Откройте приложение. В строке **Аудиодвижок** должно появиться
   `Qt FFmpeg подтверждён runtime-сообщением`. Если отображается ожидание,
   подтверждения backend нет — не засчитывайте проверку MP3/FLAC.
3. Выберите **WAV 002-A**, нажмите **Воспроизвести / продолжить**,
   **Пауза**, продолжите, затем **Стоп** и **С начала / повторить**.
   Это регрессионная проверка прежнего короткого Android-сигнала.
4. Выберите **MP3 QBuffer**. Убедитесь, что источник показывает открытый
   seekable `QBuffer`. Проверьте слышимый сигнал, паузу и продолжение,
   перемотку ползунком, остановку и повторный запуск.
5. Повторите те же действия для **FLAC QBuffer**.
6. Проверьте, что APK запускается на Huawei nova 15 Pro / EMUI 15. Этот срез
   не проверяет длительную работу в фоне, экран блокировки, гарнитуру,
   аудиофокус, переключение сети или Cloud Mail.

Запишите только результат по WAV, MP3 и FLAC, видимый статус backend и наличие
звука/управления. Не отправляйте логи целиком, имена личных файлов, реквизиты
или данные медиатеки.
