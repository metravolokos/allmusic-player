# Проверка AllMusic Player на Windows

Это заготовка приложения версии 0.0.1. Она показывает один экран, музыку пока не играет.

1. Откройте Pull Request задачи 000, затем проверку **Desktop foundation**.
2. Откройте завершённый запуск и найдите раздел **Artifacts**.
3. Скачайте **AllMusicPlayer-Windows-x64**. Для скачивания может потребоваться вход в GitHub.
4. Распакуйте скачанный файл. Если внутри есть ещё `AllMusicPlayer-Windows-x64.zip`, распакуйте и его в отдельную папку.
5. Оставьте все файлы и подпапки вместе. Запустите `allmusic-player.exe` двойным щелчком.
6. Убедитесь, что видно «AllMusic Player — проект запущен», окно можно перемещать, менять его размер и закрыть.
7. Повторите проверку отдельно на Windows 10 x64 и Windows 11 x64.

Устанавливать Qt, CMake, Ninja или Visual Studio не требуется. Если система
сообщает об отсутствующей DLL, зафиксируйте название — установка Qt для обхода
такой ошибки скрыла бы проблему упаковки.

Сборка пока не подписана цифровым сертификатом. Не отключайте защиту Windows.
Если запуск заблокирован, сообщите текст сообщения и источник скачанного файла.

Для отчёта достаточно: версия Windows и номер сборки (`winver`), ссылка на
запуск GitHub Actions, результат появления окна, читаемость текста, поведение
закрытия и сообщение ошибки, если оно было. Пароли и личные файлы не нужны.

Доступные часы ручных испытаний (Москва): Windows 10 — 09:00–20:00;
Windows 11 — 21:00–01:00 следующего дня. Это доступность устройств, а не
автоматически назначенные испытания.


## Архив 001-B1

Новый Desktop показывает локальный аудиоплеер. Для его проверки используйте
[пошаговую инструкцию звука](AUDIO-TEST.md), входящую также в архив.
Генерируемые тоны находятся в audio-fixtures; Qt/FFmpeg/VC runtime приложены.
Историческая проверка экрана задачи 000 не подтверждает звук этой версии.
