# Android Media3 002-D-M3 — проверка на Huawei

Это узкий локальный аудио-прототип: Qt Quick экран управляет Media3 ExoPlayer
через Android Java/JNI адаптер. Аудио выводится штатным Android AudioTrack;
декодирование выполняет системный Android media stack. Сеть, Cloud Mail,
пользовательские файлы и разрешения Android не нужны.

В APK встроены три коротких искусственных сигнала: MP3 440 Гц, FLAC 660 Гц и
WAV 880 Гц для регрессионной диагностики. Пункт «Отсутствующий файл» проверяет
видимую ошибку. При сворачивании приложения воспроизведение останавливается;
MediaSession, фоновая служба и управление с экрана блокировки в этой задаче
не реализованы.

## Установка

1. В GitHub откройте Actions → **Android Media3 002-D-M3** и выберите запуск с
   `source_ref=codex/002-d-media3-spike`, `android_apk=true`, `full_tests=true`.
2. Скачайте артефакт `AllMusicPlayer-002D-M3-Android-arm64-v8a-debug-…`.
   Внутри лежат APK, контрольная сумма, `BUILD-INFO.json`, отчёт аудита и лицензии.
3. Установите APK на Huawei. Его package ID отличается от 002-A и старого
   FFmpeg spike; удалять эти приложения для установки не требуется. При замене
   предыдущей 002-D сборки с другой временной подписью Android может попросить
   удалить только предыдущую 002-D копию.
4. Запустите **AllMusic Player — Media3 002-D-M3**. Интернет и вход в Cloud Mail
   вводить не нужно.

## Проверка воспроизведения

1. Выберите **Синтетический MP3 · 440 Гц**, дождитесь состояния «Готово к запуску»
   и нажмите **Play / Resume**. Подтвердите, что слышен ровный короткий тон.
2. Проверьте **Пауза**, затем **Play / Resume**. Тон должен остановиться и
   продолжиться с текущего места.
3. Нажмите примерно на середину полосы позиции. Позиция должна переместиться,
   а воспроизведение продолжиться с выбранного места. Нажмите **Stop**, затем
   снова Play: трек должен начаться с начала.
4. Во время звучания MP3 выберите **Синтетический FLAC · 660 Гц**. Активная
   строка должна измениться; после подготовки должен звучать другой тон. Повторите
   паузу, продолжение, перемотку и Stop/Play.
5. Выберите **WAV · регрессионный тест · 880 Гц** и повторите базовые действия.
   WAV здесь только для диагностики регрессии.
6. Выберите **Отсутствующий файл · проверка ошибки**. На экране должна появиться
   понятная ошибка Media3, приложение должно остаться открытым. Затем выберите
   MP3 и убедитесь, что воспроизведение снова запускается.
7. Сверните приложение или заблокируйте экран. Ожидается остановка аудио.
   Возврат к экрану не должен оставлять зависшее воспроизведение.

Для каждого MP3 и FLAC отдельно отметьте, был ли слышен звук, сработали ли
пауза/продолжение, перемотка, Stop/Play и переключение трека. При тестировании
динамика, Bluetooth или USB-ЦАП запишите только тип маршрута; конкретные кодеки
Bluetooth и модель ЦАП требуют отдельных физических испытаний.

Пришлите только результаты сценариев и текст видимой ошибки. Не нужны скриншоты,
системные логи, реквизиты, имена личных файлов или данные медиатеки.

## Граница вывода

Сборка, CI и корректно движущаяся позиция сами по себе не подтверждают слышимый
звук. Поддержка Android Media3, MP3/FLAC и seek остаётся **НЕ ПРОВЕРЕНА** до
успешной ручной проверки владельцем на Huawei.
