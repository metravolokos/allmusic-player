# 002-A — локальный Android аудио-прототип

**Дата:** 30.10.2026. **Issue:** #18. **PR:** [#19](https://github.com/metravolokos/allmusic-player/pull/19), открыт, не объединён. Проверенный кодовый commit до фиксации ручной приёмки: `8a3c075f289b44403bf5238853b1f63fccc052e0`.

## Результат и проверки

Android-экран воспроизводит встроенный синтетический сигнал 440 Гц через Android media backend Qt Multimedia. Есть воспроизведение/продолжение, пауза, стоп, повтор, статус источника/аудиовыхода и видимые ошибки. Экран прокручивается в узком/альбомном окне. FFmpeg backend исключён; приложение не использует сеть, пользовательские файлы или Android-разрешения. Производственный аудиодвижок не утверждён.

- Локально: `python3 -m unittest discover -s tests/android -v` — **8/8**, `py_compile`, `scripts/check_repository.py` и `git diff --check` — пройдены.
- [Android CI, run 41058685269](https://github.com/metravolokos/allmusic-player/actions/runs/41058685269) — успешно: APK `arm64-v8a` собран и прошёл аудит подписи, выравнивания, API 28–36, нулевых разрешений, состава native-библиотек и отсутствия GMS/Firebase. Android state-control QtTest выполнен как Desktop CTest: 7/7 на Linux и Windows.
- [Desktop CI, run 41058685268](https://github.com/metravolokos/allmusic-player/actions/runs/41058685268) — успешно: Linux 5/5 и Windows 5/5 CTest; Windows ZIP также прошёл аудит.

## Ручная приёмка владельца — 30.10.2026

По [сообщению владельца в PR #19](https://github.com/metravolokos/allmusic-player/pull/19#issuecomment-6524008425): «Всё работает, в фоне работает, после блокировки экрана работает, при возврате в приложение работает».

**Решение: ПРИНЯТО** для минимального локального Android-аудиопрототипа. Владелец подтвердил работу тестового звука и управления без сообщений о сбоях, а также работу при сворачивании приложения, блокировке экрана и последующем возвращении. Данных об отдельном тесте проводной/Bluetooth-гарнитуры нет.

**Границы результата:** исходный тестовый тон длится около 6 секунд. Не утверждается проверка длительного фонового воспроизведения, полноценной foreground-службы, MediaSession, управления с экрана блокировки, системных медиакнопок и аудиофокуса; реальный WebDAV не проверялся. Эти возможности — будущие отдельные задачи. PR остаётся открытым до решения владельца об объединении; [пошаговая инструкция](ANDROID-TEST.md) сохранена.
