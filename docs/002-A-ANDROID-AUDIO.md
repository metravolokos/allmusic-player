# 002-A — локальный Android аудио-прототип

**Дата:** 30.10.2026. **Основание:** Issue #18. **Состояние:** ожидаются PR и CI.

## Результат

Android-сборка получает отдельный экран с коротким синтетическим тоном 440 Гц.
Воспроизведение идёт из локальной копии ресурса через Qt Multimedia и системный
Android audio backend. Экран показывает состояние источника и аудиовыхода; доступны
воспроизведение/продолжение, пауза, стоп и запуск с начала. Ошибки чтения,
подготовки локальной копии и аудиодвижка видны пользователю; повтор разрешён.

Desktop-плеер не меняется. WAV генерируется при конфигурации и не хранится в Git.
Нет доступа к облаку, пользовательским файлам, сети или Android-разрешениям.
QMediaPlayer выбран только для этого эксперимента; производственный движок не
утверждён.

## Проверки

- `python3 -m unittest discover -s tests/android -v` — локально пройдено; включает
  воспроизводимость/параметры WAV и отрицательные случаи аудита APK.
- `python3 -m py_compile ...` — локально пройдено для затронутых Python-файлов.
- `python3 scripts/check_repository.py` и `git diff --check` — локально пройдены.
- Android APK build/audit и C++ QtTest — **НЕ ПРОВЕРЕНЫ локально**: в среде нет Qt
  и Android SDK/NDK. Результат CI будет указан ниже после его завершения.
- Слышимость на Huawei nova 15 Pro / EMUI 15 и маршрутах вывода — **НЕ ПРОВЕРЕНА**.
  Автоматическая сборка и тест модели управления не проверяют звук на устройстве.

## CI и APK

После создания PR сюда добавляются номер PR, SHA проверенного кода, ссылки на
Desktop/Android CI, результаты сборки и аудита. Успешный Android CI сохраняет
APK и лицензионный комплект как артефакт на 14 дней для ручной проверки владельцем.

Пошаговая установка, проверка динамика/гарнитуры и безопасная передача текста
ошибки описаны в [инструкции Huawei](ANDROID-TEST.md). Прослушивание и приёмка
остаются за владельцем.
